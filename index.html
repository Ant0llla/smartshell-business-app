Меняйте настройки клуба

Обновляйте данные, график работы, оборудование, услуги и фотографии для SmartGamer. Управляйте средствами, полученными через СБП.

Используйте привычные инструменты: команды для хостов, скидки и промокоды, кешбэк, достижения, отзывы и настройки оболочки.

Вопросы о приложении

Для кого это приложение?

Для владельцев компьютерных клубов, работающих на SmartShell. Для гостей клуба есть отдельное приложение SmartGamer.

Чем оно отличается от панели управления в браузере?

Интерфейс приложения адаптирован для телефона. Для входа используется та же учётная запись SmartShell.

Можно ли открыть смену в приложении?

Открыть смену можно в панели администратора. В приложении владелец следит за её показателями.
